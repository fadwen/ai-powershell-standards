TOPIC
    about_ModuleExample

SHORT DESCRIPTION
    Describes the behaviour of the ModuleExample module that does not belong
    to the help of one command.

LONG DESCRIPTION
    ModuleExample is an example module. It shows a module laid out in Public,
    Private, and Classes folders, with an explicit export list, a class as a
    named output type, and command help that is built from Markdown.

    There is no real service behind the module. The statuses it returns come
    from a fixed table that knows three services: Billing, Identity, and
    Reporting.

  ENVIRONMENTS

    Get-ExampleData has an -Environment parameter that accepts Development,
    Test, or Production. The default is Development. The value is recorded on
    each result:

        Get-ExampleData -ServiceName 'Billing' -Environment 'Test'

  PARTIAL FAILURE

    A service that cannot be queried does not end the command. The command
    writes a non-terminating error for that service and continues with the
    next one, so the results for the other services are still returned:

        Get-ExampleData -ServiceName 'Billing', 'Missing', 'Reporting'

    The error has the ID ServiceNotFound. To end the command at the first
    service that cannot be queried, pass -ErrorAction Stop:

        'Billing', 'Missing' | Get-ExampleData -ErrorAction Stop

  OUTPUT

    Get-ExampleData emits ExampleServiceResult objects. Each object has the
    properties ServiceName, Environment, Status, and CheckedAt. Status is
    Healthy, Degraded, or Unavailable. The IsUsable() method returns $true
    when the status is Healthy or Degraded:

        Get-ExampleData -ServiceName 'Billing', 'Reporting' |
            Where-Object { $_.IsUsable() }

  HELP

    The help for Get-ExampleData is written as Markdown in
    docs/ModuleExample/Get-ExampleData.md and compiled to
    en-US/ModuleExample-Help.xml. The function file carries only an
    .EXTERNALHELP keyword and a one-line synopsis. To change the help, edit
    the Markdown and compile it again. Do not edit the XML file.

    This topic is a plain text file that is written by hand.
