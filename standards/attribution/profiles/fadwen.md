# Attribution

Coding agents that follow the PowerShell standards read this file when they write an author into
new code: the `.NOTES` of comment-based help and of help Markdown, and the `Author`, `CompanyName`,
and `Copyright` keys of a new module manifest (DOC-18). Fill in the values that should appear. A
line with no value is left out, and an agent does not invent one.

The standards installer creates this file when it is missing and never changes it afterwards, so
these details belong to this repository.
